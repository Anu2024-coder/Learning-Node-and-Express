//need of express.js instead of setting server using http module

Feature / Point	                       HTTP Module (Default Node.js)	                                                    Express.js
Code simplicity                  	   You have to manually handle routing, parsing requests, sending responses, etc.	    Express provides simple methods like app.get(), app.post() — very clean and short.
Routing	                               Must manually check req.url and req.method for each route.	                        Built-in routing system to handle multiple URLs easily.
Middleware                  	       No built-in middleware support — you must write everything yourself.	                Built-in + third-party middleware (like body-parser, cookie-parser, etc.) handle requests easily.
Handling JSON / form data   	       You must manually parse the request body.	                                        Express automatically parses JSON and form data with one line (app.use(express.json())).
Error handling	                       You must handle errors manually for every route.                                     Centralized error-handling mechanism.
Reusability	                           Hard to organize code for large apps.	                                            Easy to structure large apps using routers and middleware.
Performance	                           Slightly faster for very small apps.	                                                Tiny overhead, but much easier to scale.
